# Algorithm Analysis

An important part of studying data structures is understanding how their efficiency changes as the input size grows.

The following table summarizes common theoretical time complexities.

| Data Structure | Search | Insertion | Deletion |
|----------------|--------|-----------|----------|
| Linked List | O(n) | O(1)* | O(n) |
| Binary Search Tree | O(h) | O(h) | O(h) |
| AVL Tree | O(log n) | O(log n) | O(log n) |
| Binary Heap | O(n) | O(log n) | O(log n) |

*Linked-list insertion is O(1) when the insertion position or required node reference is already known. Otherwise, locating the position may take O(n).*

For a Binary Search Tree, `h` represents tree height. A balanced BST has a height of O(log n), while a highly skewed BST may have a height of O(n).

A binary heap supports O(1) access to its highest-priority root element, but searching for an arbitrary value generally requires O(n).

These comparisons demonstrate why selecting the appropriate data structure is important for designing efficient algorithms.
