# A310: Problem Solving with Data

This repository contains my coursework, labs, assignments, exercises, and programming projects for **A310: Problem Solving with Data** at Indiana University Bloomington.

The repository will be updated throughout the Fall 2026 semester as new topics, assignments, and projects are completed. Work is organized by week to document my progression through the course and provide a clear record of the data structures, algorithms, and problem-solving techniques covered.

## Course Information

**Course:** A310 — Problem Solving with Data  
**Institution:** Indiana University Bloomington  
**Semester:** Fall 2026  
**Primary Language:** Python  

The course focuses on applying data structures and algorithms to solve problems efficiently. Early coursework emphasizes implementing fundamental data structures from first principles, while later coursework expands into data manipulation, visualization, analysis, and data science applications using Python libraries and frameworks.

## Topics

Topics covered throughout this repository will include concepts related to data structures, algorithms, Python programming, and data-driven problem solving.

### Data Structures & Algorithms

- Object-oriented programming
- References and linked structures
- Linked lists
- Stacks and queues
- Trees
- Binary search trees
- AVL trees
- Heaps
- Graphs
- Recursion
- Searching algorithms
- Sorting algorithms
- Algorithm analysis
- Time and space complexity
- Asymptotic notation
- Data structure selection and trade-offs

### Data & Problem Solving

Later coursework will expand into topics such as:

- File processing
- Data acquisition
- Data cleaning and preprocessing
- Data manipulation
- Exploratory data analysis
- Data visualization
- Web scraping and APIs
- Statistical concepts
- Machine learning fundamentals
- Model evaluation
- Data-driven problem solving
- Ethical considerations in data collection and analysis
